# Pre-1.0 release claims policy

OpenRide is an infrastructure project under active extraction and hardening. Until `1.0.0`, public release notes must distinguish three categories:

1. **Implemented** — code exists, is tested and has an executable path.
2. **Foundation** — schemas, interfaces or persistence primitives exist, but the complete production workflow is not finished.
3. **Planned** — documented architecture or roadmap only.

A badge, README section, release note or social post should not turn a Foundation or Planned capability into an Implemented claim.

Production readiness for real passenger transport is a separate decision from software compilation. It requires operator-specific validation of safety, regulation, insurance, identity/KYC, privacy, payments, fraud controls, incident response, observability and recovery.
