# Public surface checklist

Before merging architecture or branding work to `main`, verify that a new visitor sees a consistent project identity:

- repository name: OpenRide;
- README title and hero: OpenRide;
- API public identity: OpenRide;
- compatibility runtime explicitly labeled compatibility;
- package/readme examples use canonical OpenRide module paths where available;
- license detection is AGPL-3.0-or-later;
- GitHub About description/topics use OpenRide metadata;
- no roadmap-only service is presented as implemented;
- legacy FlashX identifiers are either intentionally compatible or scheduled for migration.
